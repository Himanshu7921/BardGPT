# Code of Conduct

## 1. Purpose

The goal of this project is to maintain a productive, respectful, and inclusive environment for contributors and users of BardGPT.  
This Code of Conduct outlines expected behavior and establishes standards to ensure collaboration remains constructive and professional.

## 2. Expected Behavior

All participants are expected to:

- Demonstrate respect and professionalism in all interactions.
- Provide constructive feedback and welcome diverse viewpoints.
- Accept responsibility for their actions.
- Support an inclusive environment for contributors of all backgrounds and skill levels.
- Use welcoming and inclusive language when discussing issues, ideas, and implementations.

## 3. Unacceptable Behavior

The following behavior is strictly prohibited:

- Harassment, discrimination, or derogatory comments of any kind.
- Personal attacks or insults directed at individuals or groups.
- Disruptive or intentionally unproductive behavior.
- Publishing private information of others without explicit permission.
- Any conduct that could be reasonably interpreted as hostile, exclusionary, or disrespectful.

## 4. Scope

This Code of Conduct applies to:

- All interactions within project spaces (GitHub issues, PRs, discussions).
- Any public or private communication involving project maintainers or contributors.
- Any location where contributors represent the project or its community.

## 6. Consequences of Violations

Violations of this Code of Conduct may result in actions including:

- A formal warning
- Temporary or permanent ban from participating in the repository
- Reversal or rejection of contributions
- Any other action deemed appropriate by the maintainers
